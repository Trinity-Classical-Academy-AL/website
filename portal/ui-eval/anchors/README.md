# Anchors

Ceiling and floor screenshots for the judge panel. They are not in git.

- `ceiling/` — Linear settings, Stripe dashboard, Vercel project settings, Shopify or Squarespace announcement bar, Linear or Stripe lists, a Brightwheel-style parent list.
- `floor/` — a capture of the portal from before the v5 pass, a generic template admin, and any frame Bryant rejects.

The judge script refuses to score a round that has fewer than two ceiling images and one floor image.
